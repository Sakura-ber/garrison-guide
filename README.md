# 卫戍协议配队台

《明日方舟》卫戍协议 · 规程序列Ⅰ的配队工具。可以查干员和盟约、构筑上场与整备卡组，或按本局禁用情况给八套流派排序。流派页包含叠层、输出、过渡和转型思路。

## 下载与使用

[下载配队台发布包](https://github.com/Sakura-ber/garrison-guide/releases/latest)

- **Windows 10 22H2 / Windows 11**。按系统类型下载 `win-x64` 或 `win-arm64`，解压整个 ZIP 后运行 `GarrisonGuide.exe`。ZIP 内含 .NET 运行时和离线中文识别模型。界面使用 Microsoft Edge WebView2 Runtime。若系统缺少该组件，可[从 Microsoft 安装 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/#download-section)。
- **macOS 14 及以上，Apple 芯片**。解压 `macOS-arm64` 后打开「卫戍协议配队台.app」。首次读屏按系统提示允许屏幕录制，也可以导入截图。

进入「开局推荐」，读取游戏画面或导入截图，核对盟约和禁用干员，再选择「确认并推荐流派」。名单在下方时，滚动游戏界面后用「补读屏幕」。若独占全屏游戏截取为空，可导入游戏截图，也可以切换到无边框窗口模式。截图识别在设备上完成。

游戏素材归原权利人所有。攻略及资料来源见应用内链接。
